# Safe Mass Refactoring Rule

При выполнении массового рефакторинга или масштабных изменений кода (изменение множества файлов или строк):
1. **Всегда пишите и запускайте тесты** (например, unit-тесты) перед завершением задачи для проверки тех модулей, которые были затронуты изменениями.
2. **Строго избегайте слепых regex-замен** (в том числе через самописные Python или bash-скрипты) для модификации исходного кода. Предпочитайте точечные изменения через нативные инструменты редактирования (`multi_replace_file_content`, `replace_file_content`) с валидацией заменяемого текста, либо AST-aware инструменты рефакторинга.
