# 📘 Краткое руководство пользователя SVControl

Мод **SVControl** (Server Control) — это мощный инструмент для строителей и администраторов серверов Minecraft, который добавляет функционал "контроля версий" (подобный Git) прямо в игру. С его помощью вы можете сохранять свои постройки, отменять изменения, переключаться между разными вариантами дизайна и экспортировать результаты в Litematica.

---

## 🟢 1. Начало работы (Создание проекта)
Любая работа начинается с выделения **Проекта** — кубической зоны, внутри которой будет действовать контроль версий.

1. Возьмите в руки **Деревянный меч** (либо используйте команды).
2. Нажмите **Левую кнопку мыши (ЛКМ)** по первому углу вашей постройки (или введите `/svcntrl pos1`).
3. Нажмите **Правую кнопку мыши (ПКМ)** по противоположному углу (по диагонали) (или введите `/svcntrl pos2`).
4. Напишите в чат команду: `/svcntrl project create <ИмяПроекта>`
   *Например: `/svcntrl project create Spawn`*

Ваш проект создан! Теперь он активен (выбран), и все дальнейшие команды будут применяться к нему.

*💡 Если вы сбились или хотите перевыбрать проект позже, просто посмотрите на него и введите `/svcntrl raycast` (и нажмите ПКМ по подсветке), либо используйте `/svcntrl select <ИмяПроекта>`.*

---

## 💾 2. Сохранение и Восстановление
Работая над проектом, вы можете в любой момент сохранить его состояние (Снапшот), чтобы потом к нему вернуться.

- **Сохранить прогресс:** `/svcntrl save <НазваниеСейва>`
  *(Например: `/svcntrl save start_roof`)*
- **Посмотреть все сохранения:** `/svcntrl snapshots`
- **Откатиться к сохранению:** `/svcntrl restore [manual|auto] <id> [branch]`
  *(Например: `/svcntrl restore manual 1`. Категория (`manual`/`auto`) и ветка опциональны, по умолчанию `manual` и текущая ветка. **Внимание:** перед откатом мод автоматически сохранит ваше текущее неудачное состояние в "Автосейв", так что вы ничего не потеряете!)*

### 👁️ Превью (Предпросмотр)
Не уверены, к какому сохранению откатываться? Посмотрите на него "фантомно"!
- `/svcntrl preview start [manual|auto] <id> [branch]` — поверх мира наложатся фантомные блоки из прошлого сохранения. Вы можете летать сквозь них.
- `/svcntrl preview stop` — выключить предпросмотр.

## 🌿 3. Ветки (Branches) - Магия Git
Допустим, вы построили стены и теперь хотите попробовать **два разных варианта крыши**: из дерева и из камня. Вам не нужно строить два дома! Вы можете использовать Ветки.

1. **Создайте ветку для дерева:** `/svcntrl branch create wood_roof`
2. **Переключитесь на неё:** `/svcntrl branch checkout wood_roof`
3. Стройте деревянную крышу. Сохраните прогресс: `/svcntrl save done_wood`
4. **Вернитесь на основную ветку:** `/svcntrl branch checkout main` (мод тихо сохранит `wood_roof` и вернет вам дом без крыши).
5. **Создайте ветку для камня:** `/svcntrl branch create stone_roof`
6. **Переключитесь на неё:** `/svcntrl branch checkout stone_roof`
7. Стройте каменную крышу! 

Теперь вы можете вводить `/svcntrl branch checkout wood_roof` и `/svcntrl branch checkout stone_roof`, и ваша крыша будет мгновенно перестраиваться из дерева в камень и обратно!

*Полный список ваших веток:* `/svcntrl branch list`

## 📦 4. Экспорт и Диффы (Litematica)
Вы можете выгрузить свои постройки из мода прямо в файлы `.litematic`, чтобы перенести их в одиночный мир или поделиться с друзьями.

- **Экспорт конкретного снапшота:** `/svcntrl export [manual|auto] <id> [branch]`
  *(В **одиночной игре** мод тихо сохранит `.litematic` в папку `schematics/svcntrl/` прямо в вашей игре! На **серверах**, если включено в конфиге, мод даст вам прямую ссылку на скачивание в чат).*
- **Экспорт Диффа (Патча):** `/svcntrl export diff [manual|auto] <baseId> <targetId> [branch]`
  *(Экспортирует **только те блоки и сущности**, которые изменились. Идеально для создания лайтматик "дострой вот это").*
- **Кросс-экспорт:** `/svcntrl export diff_cross <Ветка1> <id1> <Ветка2> <id2>`
  *(Экспортирует разницу между деревянной и каменной крышей).*
- **Резервная копия всего:** `/svcntrl export all`
  *(Упакует все ветки и сохранения в один `.zip` архив).*

---

## 🤝 5. Командная работа
Если вы строите с друзьями, вы можете дать им доступ к своему проекту:
- **Добавить строителя:** `/svcntrl trust <НикИгрока>`
- **Удалить строителя:** `/svcntrl untrust <НикИгрока>`
*(Только владелец проекта (тот, кто его создал) может раздавать права).*

## 🛠️ Настройки сервера (Для админов)
Конфиг мода лежит в папке сервера: `config/svcntrl.json`.
- `outlineParticle` — тип частиц выделения границ.
- `allowPublicExport` (по умолчанию `false`) — если включить (`true`), команда `export` будет загружать схемы на `tmpfiles.org` и выдавать игрокам в чат короткую ссылку на скачивание. Очень удобно для игроков!
- `maxRegionVolume` (по умолчанию `100000000`) — лимит блоков в одном проекте (100 млн), защищает сервер от зависаний при случайном выделении миллиардов блоков.
- `autoSaveOnBranchSwitch` (по умолчанию `true`) — делает автоматический снапшот перед сменой веток.
- `autoSaveOnRestore` (по умолчанию `true`) — делает автоматический снапшот перед откатом к предыдущей версии.

Приятной стройки! 🏗️
