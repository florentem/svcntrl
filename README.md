# Svcntrl (Server Control)

Мод для управления, сохранения и восстановления серверных построек и зон. 
Основная цель мода — позволить доверенным игрокам выделять зоны (проекты) в мире и создавать их легковесные снапшоты, которые можно мгновенно восстанавливать или экспортировать в формат Litematica.

## Основные концепции
- **Проект (Project)** — именованная кубическая зона в мире. У проекта есть владелец и участники.
- **Снапшот (Snapshot)** — слепок блоков и сущностей проекта в определенный момент времени. Снапшоты бывают ручными (созданными командой) и автоматическими (создаются перед восстановлением зоны или переключением веток).
- **Ветки (Branches)** — изолированные линии сохранений. Позволяют разрабатывать разные варианты постройки в одном и том же месте, мгновенно переключаясь между ними. По умолчанию все проекты создаются в ветке `main`.
- **Превью (Preview)** — клиентская визуализация (фантомные блоки) снапшота до его фактического восстановления, позволяет посмотреть, как выглядела зона.
- **Диффы (Diffs)** — экспорт разницы между двумя снапшотами (патчи), что позволяет обмениваться только измененными блоками.

## Команды

Все команды начинаются с `/svcntrl`. Большинство команд связаны с управлением проектами.
Управление выделением осуществляется с помощью деревянного меча (ЛКМ — первая точка, ПКМ — вторая точка), либо командами `/svcntrl pos1` и `/svcntrl pos2`.

### Управление проектами
- `/svcntrl project create <имя>` — создать новый проект из текущего выделения.
- `/svcntrl project delete <имя>` — удалить проект (требует подтверждения).
- `/svcntrl project list` — список всех проектов сервера.
- `/svcntrl project info <имя>` — информация о проекте (размер, владелец, участники).
- `/svcntrl project rename <старое_имя> <новое_имя>` — переименовать проект.

### Управление доступом
- `/svcntrl trust <игрок>` — добавить участника в проект.
- `/svcntrl untrust <игрок>` — удалить участника из проекта.

### Администрирование (Admin Bypass)
Система разрешений работает через Fabric API (и LuckPerms, если установлен).
- Игроки с уровнем OP 3+ или с разрешением `svcntrl.admin` имеют **полный доступ ко всем проектам**.
- Они могут обходить проверки `isOwner` и `isMember`, удалять чужие сломанные проекты, делать бекапы или просматривать снапшоты любого игрока на сервере.

### Работа со снапшотами
- `/svcntrl save <название> [ветка]` — создать ручной снапшот текущего активного проекта (ветка опциональна).
- `/svcntrl snapshots` — посмотреть список всех снапшотов проекта.
- `/svcntrl restore [категория] <id> [ветка]` — восстановить проект до указанного снапшота (создаёт авто-снапшот перед этим). Категория (`manual`/`auto`) и ветка опциональны.

### Ветки (Branches)
- `/svcntrl branch list` — показать все ветки текущего проекта.
- `/svcntrl branch create <имя>` — создать новую ветку (копирует текущее состояние).
- `/svcntrl branch checkout <имя>` — переключиться на другую ветку (автоматически сохраняет текущую ветку перед уходом).
- `/svcntrl branch delete <имя>` — удалить ветку (нельзя удалить `main` или текущую ветку).

### Экспорт и Превью
- `/svcntrl export [категория] <id> [ветка]` — экспортировать снапшот в формат `.litematic`. В одиночной игре сохраняется прямо в `schematics/svcntrl/`.
- `/svcntrl export diff [категория] <baseId> <targetId> [ветка]` — экспортировать только разницу (патч) между двумя снапшотами.
- `/svcntrl export diff_cross <baseBranch> <baseId> <targetBranch> <targetId>` — экспортировать разницу между двумя разными ветками.
- `/svcntrl export all` — экспортировать весь проект (все ветки и снапшоты) в один `.zip` архив.
- `/svcntrl preview start [категория] <id> [ветка]` — включить предпросмотр снапшота (вы будете видеть фантомные блоки).
- `/svcntrl preview stop` — выключить предпросмотр.

### Прочее
- `/svcntrl select <имя>` — сделать проект активным для вас (для команд save/restore/preview).
- `/svcntrl outline` — включить/выключить отображение границ активного проекта частицами.
- `/svcntrl raycast` — включить режим выбора проекта "взглядом". Посмотрите на нужный проект, и он подсветится другим цветом. Нажмите ПКМ, чтобы выбрать его.

## Конфигурация
Конфиг находится в `config/svcntrl.json`.
- `outlineParticle` — тип частиц для отображения границ (по умолчанию `minecraft:flame`).
- `outlineFrequencyTicks` — частота спавна частиц (в тиках, по умолчанию `15`).
- `allowPublicExport` — разрешить ли автоматическую выгрузку экспортов (диффов) на внешний обменник `tmpfiles.org` и выдачу прямой ссылки в чат (по умолчанию `false`). Если `false`, сохраняет только локально в папку сервера.
- `maxRegionVolume` — максимальный объем проекта в блоках (по умолчанию `100000000`, 100 млн блоков). Предотвращает OOM.
- `autoSaveOnBranchSwitch` — делать ли автоматический снапшот перед переключением веток (по умолчанию `true`).
- `autoSaveOnRestore` — делать ли автоматический снапшот перед откатом на предыдущее состояние (по умолчанию `true`).
- `raycastParticlePool` — набор частиц для визуализации режима `raycast`.
